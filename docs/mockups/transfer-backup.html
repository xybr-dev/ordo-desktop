A. Transfer & Backup, interactive

The administrative home for moving Celebrations and protecting the parish (Decision 191). Protect this parish comes first (Decision 199), then Celebration Packages with their version history (Decision 185), then every Parish Backup, including automatic safety backups (Decision 201). One backup's drive isn't connected, so it's Unavailable, not damaged (Decision 231).

B. Export celebration, choosing the Celebration

From this page the export first asks which Celebration; from Masses it starts with the Celebration already chosen.

C. Ready with warnings

Unfinished plans can travel (Decision 192). The plan list is informational: a package is always the whole Celebration (Decision 191).

D. Cannot export

Only problems that make the file untrustworthy stop it; a Celebration with no Mass plans is one.

E. No changes since the last version

The existing package version is copied as it is, keeping its identity (Decision 190).

F. Export complete

Stays open after the file is read back and verified, with the eject reminder (Decision 196).

G. Create parish backup

Always the whole parish, with no checkboxes (Decisions 197, 199).

H. Backup complete

Verified by reading it back; this clears the reminder (Decision 198).

I. Import review

A dedicated workspace with two layers: the exact presentation installs as prepared, while library changes are staged (Decision 181). Import stays unavailable until every decision is made.

J. A decision

A possible Song match is decided in a slide-over above the workspace (Decision 183).

K. Ready to import

With nothing left to decide, Import celebration commits everything at once (Decision 184).

L. Restore parish backup

Current parish and Backup side by side; restore replaces, never merges. Restore parish stays disabled until the current parish is protected (Decision 200).

M. Restore confirmation

After protection, a centred confirmation with Keep current parish focused.

N. A damaged backup and a package's versions

A backup that fails its checks is kept with what failed, and can't be restored (Decision 231). A package expands to its versions.
