A. Review a liturgy file, interactive

Opened from a Celebration’s … menu, Transfer & Backup Import, or a Reading item in the Mass Planner. The file is matched to a Celebration by date and compared, entry by entry, with each Mass plan in its language. Select entries on the left; decide the open ones; Copy stays off until nothing is left to decide.

B. Text changed by hand in a plan

The 09:00 plan’s Gospel Acclamation was edited. Both versions show side by side with the differences marked; the operator keeps one.

C. A plan with no item for the entry

The 17:00 plan came from the Weekday template and has no Second Reading. Add the item to Liturgy of the Word, or skip it for that Mass.

D. Reused text marked Needs review

The 06:00 plan was reused from last Sunday. Its readings are replaced by the file’s and lose the Needs review mark; no decision needed.

E. Choosing another Celebration

The date match can be overridden. A Celebration on another date warns that the readings may not suit it.

F. Everything decided

Copy is available. The counts show what will happen to each plan.

G. Copied

Each plan’s readiness updates. Undo is in each plan’s History, not a single parish-wide undo.

H. No plan in the file’s language

A Tagalog file for a Celebration with only Cebuano and English plans. Nothing is kept; add a Tagalog Mass first.

I. An invalid file

Strict Invalid (Decision 223): the reason, Choose another file and View technical details. Ordo never imports part of a liturgy file.

J. A file from a newer Ordo

A valid file in a newer format is not called corrupt; it says which version can read it.
