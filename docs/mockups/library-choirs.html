A. Choirs, interactive

The Library's Choirs view at 1366 × 768 (proposed Decision 278). Choirs are on the left; the selected choir's short label, preferred languages and private notes fill the right and save as you type. Click the name to rename it: its Arrangements and Mass plans show the new name. Repertoire is a table with one row per Arrangement that names this choir, and Open goes to it.

B. Adding a choir

Add choir opens a name field at the top of the list. Only a name is needed (Decision 221); Enter adds the choir and selects it.

C. A name that already exists

Names are compared ignoring case and spacing. A match stops Add and offers to select the existing choir instead, even when it's archived.

D. Preferred languages

+ Language opens the same search over Ordo's language list as Arrangement details, so a choir's languages and its Arrangements' languages always match.

E. Archived choir

With Show archived on, an archived choir can be inspected and restored. Selectors stop suggesting it, but Arrangements and Mass plans that name it keep it (Decision 87).

F. No choirs yet

The same workspace with nothing in it: Add choir first, and three short points saying choirs are optional (Decision 221).

G. Repertoire in a narrow window

When the pane is too narrow for the table’s columns, each Song becomes a card with its Arrangements inside, and Shared with moves under the Arrangement it belongs to.
