A. Settings → Parish, interactive

Settings is a short list of pages (Decision 280). Parish holds the name and the defaults new Mass plans copy: regular presiders, the default presider and the default location (Decision 89). Changes save as you type.

B. Displays

This computer's displays as Windows or Linux arranges them, the congregation display, Identify displays, and Calibration with Output Fit and a fitted preview (Decisions 46, 50, 202).

C. Calibration pattern showing

Only the calibration frame ever reaches the congregation display from Settings; Return to black ends it and records the check.

D. Identify displays

Each display shows its number for a few seconds.

E. The congregation display changed

Changing it asks for a calibration check before relying on the saved Output Fit (Decision 47).

F. Congregation display disconnected

It becomes Unavailable; Ordo never reassigns it silently (Decision 202).

G. One display

With only the operator display, the congregation display is Not assigned and Presenter opens with output off.

H. Interface

Interface scale from 100% to 200% for this computer (Decision 234). Slides keep their 1920 × 1080 composition.

I. Interface at 150%

Everything Ordo draws grows together; the slide only grows as a picture.
