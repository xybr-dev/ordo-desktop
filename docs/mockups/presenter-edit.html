A. Live on the Entrance Song chorus, interactive

Click the Presenter, then press Ctrl+E (or Edit slide above the timeline). Program freezes on the slide as it is; the edit panel opens over the timeline with the text focused. Every keystroke saves to this Mass plan and updates Preview only. Esc or Ctrl+Enter closes it; Space takes the correction live.

B. Editing a reused Song section

The choir sings a different second line. The chorus appears twice in this Mass, so by default the correction applies to both; the Library Arrangement stays as it was. Preview (in the panel and the Output Dock) shows the correction while Program still shows the old slide.

C. Only this slide

The operator limits the correction to this occurrence; the other chorus keeps the Library words.

D. Done: Preview corrected, Program still frozen

Both chorus slides are marked Edited, the item Edited live · Mass-local, and the Ordo rail shows it too. Program still holds the old frame; Space takes the correction live. After Mass the edit can be offered back to the Library through a review.

E. A reading from the imported liturgy

Same panel, with the reading’s text and reference. The imported liturgy isn’t changed; the correction belongs to this Mass.

F. Ctrl+E on an operator-only Cue

Nothing opens and Program doesn’t freeze. The message says why; Edit slide is disabled while such a Cue is in Preview.

G. Rehearsal, output disabled

With no congregation output there is nothing to freeze; the edit still saves to this Mass plan.
