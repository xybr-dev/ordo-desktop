A. Theme library, interactive

Themes in the rail. The protected Ordo Black has its own section; parish Themes show a canonical preview, how many Mass plans use them, and their status (Decisions 103, 222). Click a preview or Edit to open the editor; change something and Save to see propagation and Undo.

B. Theme actions

Edit, Rename, Duplicate, Set as parish default and Archive (Decision 103). The parish default can't be archived until another Theme takes over.

C. Archived Themes shown

An archived Theme stays with the Mass plans that already use it; it's only hidden from new choices.

D. Only the built-in Theme

Never an empty library (Decision 222): Ordo Black is there, Built in and Parish default, and Create parish theme starts a copy of it.

E. Theme Editor with unsaved changes

One authoritative 16:9 frame beside Typography, Appearance and Layout (Decisions 96, 100). The specimen bar only changes the test content. Because 12 plans use Parish Dark, the warning names them before Save (Decision 97).

F. Appearance with an image background

Solid colour or one image, with Cover crop, focal point, overlay and a required fallback colour (Decision 100). This image isn't 16:9 and is under 1920 × 1080, so both advisories show (Decision 225). Contrast is computed from the composed result.

G. Saving a shared Theme

Save asks once when other plans will change, and offers Duplicate instead.

H. After Save

Save feedback names the Theme and the plans updated, with Undo (Decision 98). This change made new overflow, so the toast also offers Review affected plans (Decision 99).

I. Review affected plans

Only plans with new problems are listed, grouped by plan, each opening at its slide.

J. Leaving with unsaved changes

Exactly three outcomes (Decision 101).

K. Duplicate Theme

The name starts as “… copy”; the copy carries the unsaved changes and the editor switches to it (Decision 102).

L. History

Every Save is a revision with its change summary and the plans it updated; restoring makes a new revision (Decision 104).

M. A missing background image

The Theme renders its fallback colour, is marked Degraded, and keeps the missing reference with Replace or Remove (Decision 224).

N. Ordo Black opened

The built-in Theme can be viewed and duplicated but not edited (Decision 103).
