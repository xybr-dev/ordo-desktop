A. Every editor, interactive

One working planner, opened on the First Reading. Select any item in the outline to open its editor. Every field regenerates the item's Cues as you type, and the Inspector follows. A suggested path:

  1. Edit the First Reading text and add a blank line: a new passage Slide appears. Switch Full-reading projection off and the passage Slides go away; the title and closing response stay.
  2. Open 7. Responsorial Psalm. Edit the refrain once and every occurrence changes. Switch Project the verses on to see the cantor verses become Slides.
  3. Open 3. Greeting. It's linked, so its words are read-only. Press Customize for this Mass, add an exchange, and set the header to Override.
  4. Open 1. Pahibalo. Edit the private delivery context while the item is still linked. Then customize it and press Add image Slide.
  5. Press + and add a Hold, a Custom sequence, a Response or Prayer (the picker opens) or a Reading.

B. Reading with the full passage projected

Readings belong to the Mass, so they have no Library link. The proclamation title and reference make the identification Slide. With projection on, the text paginates into passage Slides, and a blank line always starts a new one. The closing exchange keeps the lector's prompt private and projects the congregation's response.

C. Reading kept private (the default)

With projection off, the passage is still stored. Presenter shows it to the operator beside the identification frame; the congregation sees only the title. This Second Reading has no closing exchange yet, so its only Cue is the title.

D. A new Reading

Added after the Responsorial Psalm. The title field takes focus, and the closing exchange starts from the template's default prompt and response. Readiness counts the item as incomplete until it has a title and text.

D2. Responsorial Psalm

Mass-owned, like the Readings. The refrain is one linked text, projected before the first verse and after every verse. By default each cantor verse is a Wait Cue: Program keeps the refrain up while the cantor sings, and the verse text shows privately to the operator. The header follows the plan default SALMO RESPONSORYO unless hidden or overridden.

D3. Responsorial Psalm with projected verses

With Project the verses on, each verse becomes a Reading-passage Slide under its own card, and the refrain still returns after each one.

E. Response or Prayer, linked to the Library

The Greeting uses Pagtimbaya from Responses & Prayers. Each exchange has an optional operator-only prompt with its role, then the required response, and shows the Cues it produces. While the item is linked, its words are read-only here; Customize for this Mass makes a local copy.

F. Choosing a Response for a new item

Adding Response or Prayer opens the same staged picker that Songs use. Selecting an entry previews its first projected Slide and its prompt and response order. Write for this Mass only starts an empty local item instead.

G. Customized Response

After Customize for this Mass, the banner names the override. Here the header is overridden for this item, and a third exchange has been added for the choir. Exchanges can be reordered or removed. Return to library source lists what would be dropped.

H. General Presentation with private delivery context

The opening Pahibalo is linked to Pahibalo sa Domingo. Its Slides are read-only here, but the private delivery context belongs to this Mass item and stays editable. The context shows beside the frame in the Inspector and in Presenter, never on the projector. Each Slide can override the 8-second auto-play default.

I. Customized General Presentation with an image Slide

Customized for this Mass, with an image Slide added at 12 seconds. The image is fitted inside the safe area and never cropped. Its description is for the operator and is not projected.

J. Hold

A Hold added after the Gospel and labelled Homily. It has no projected content, only an operator label. The editor explains how a Hold differs from a Blackout item.

K. Custom sequence

For an unusual moment, here a blessing of the children before the Dismissal, a Custom sequence holds Cues of different types in any order. Add Cue offers each type. The selected Cue's fields sit below the list, and the Inspector shows whether that Cue projects.
