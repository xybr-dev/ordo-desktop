A. Details of a shared Arrangement

Opened from Arrangement details in the editor header. Changes are staged until Save details; Cancel discards them. Because two Choirs sing this exact rendition, the scope is stated before saving. Duplicate Arrangement is the safe path when one Choir's version should branch.

B. New Arrangement

The same surface, titled New Arrangement, without Duplicate, and committing with Create Arrangement. Only a language is required; pressing Create without one says so beside the field and saves nothing.

C. After Create Arrangement

The new Arrangement opens in its Lyrics task with No sections yet and Add first section focused. Ordo doesn't invent a Verse 1.

D. Adding a section

A small anchored popover with one required name and editable suggestions; the next number is proposed (Bersikulo 3). Add section selects the new section and puts the cursor in its lyrics.

E. Renaming a section

The section name above the lyrics is the name field: click it and type. Enter or clicking away renames the section everywhere it appears in the Sequence, with Undo; Esc puts the old name back. The section list has no rename button any more (proposed Decision 275).

F. A choir that isn't in the list yet

+ Choir opens a search over the parish's active choirs. When nothing matches what was typed, the first row offers Create “…”, and Enter picks it. Archived choirs aren't suggested (Decision 221).

G. After Create

The choir is saved straight away with only its name and is selected here. Its short label, preferred languages and notes are filled in later in Library → Choirs. The Arrangement itself still waits for Save details.

H. Adding a language

Languages come from Ordo's built-in list instead of being typed in, so the Library, Mass plans and templates name each language the same way. Search also covers other names: ilong finds Hiligaynon. When nothing matches, the picker says so and offers no Create (proposed Decision 277).
