A. Details of a shared Arrangement

Opened from Arrangement details in the editor header. Changes are staged until Save details; Cancel discards them. Because two Choirs sing this exact rendition, the scope is stated before saving. Duplicate Arrangement is the safe path when one Choir's version should branch.

B. New Arrangement

The same surface, titled New Arrangement, without Duplicate, and committing with Create Arrangement. Only a language is required; pressing Create without one says so beside the field and saves nothing.

C. After Create Arrangement

The new Arrangement opens in its Lyrics task with No sections yet and Add first section focused. Ordo doesn't invent a Verse 1.

D. Adding a section

A small anchored popover with one required name and editable suggestions; the next number is proposed (Bersikulo 3). Add section selects the new section and puts the cursor in its lyrics. Renaming uses the same popover.
