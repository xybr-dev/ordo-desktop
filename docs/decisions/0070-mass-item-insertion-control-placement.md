# Mass-item insertion control placement

- **Add Mass item** is a local Mass-outline action and appears at the top-right of the Mass outline header rather than at the bottom of the ordered list.
- At comfortable widths it uses the explicit label **+ Add Mass item**. At constrained widths it may compact to a `+` icon button with the same accessible name and a tooltip.
- The insertion workflow and default placement are defined in Decision [71](0071-add-mass-item-workflow-and-editor-presets.md). Decision [72](0072-mass-outline-header-action-ownership.md) deliberately omits an outline-wide overflow menu; the complete per-item context menu remains in the immediate interview queue.
