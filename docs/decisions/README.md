# Decisions

Why Ordo is shaped the way it is: one decision per file, `NNNN-kebab-title.md`. The format is the one
clockout, personal-admin and personal-admin-os use, so every series reads the same
([0270](0270-record-decisions-one-per-file.md)). This is the detailed decision ledger that `AGENTS.md`
names: consult it where `MILESTONES.md`, `CONTEXT.md`, `DESIGN.md` and `MVP-PLAN.md` are silent.

- **New record:** `python docs/decisions/adr.py new "Title" --tags a,b`, then fill in its sections.
- **Status:** `proposed` → `accepted` (or `rejected`). A changed decision gets a new record with
  `supersedes: [N]`; record N becomes `superseded` with `superseded_by`. A decision that replaces only
  part of N lists it in `amends`; N stays `accepted`, gains `amended_by`, and carries a forward notice
  at the top saying what remains authoritative. Accepted records are not rewritten beyond typos, links
  and forward notices.
- **Dates:** `date` is when the decision was made, `recorded` when it was written down.
- **Sources:** a path in this repo, or `<repo>:<path>` for a sibling repo (e.g. `clockout:docs/...`).
- **Check:** `python docs/decisions/adr.py check` validates every record, both directions of every
  supersede and amend link, and this index. `cargo xtask verify` and CI run it.
- **Index:** the table below is generated from the frontmatter by `python docs/decisions/adr.py index`.

Records 0001–0269 were split from the single-file ledger `decision.md` on 2026-10-27, keeping their
numbers, so "Decision 268" in older text is [0268](0268-make-ordo-windows-only-for-the-mvp-and-defer-linux.md).
They keep the ledger's bullet form instead of the Context / Decision / Alternatives / Consequences
sections. Their dates are when each entered the repository: 0001–0260 arrived together on 2026-08-29,
after the planning interview that made them. Their tags were assigned from the titles. Decision 12a
lives inside [0012](0012-safe-live-operations.md). The ledger's preamble, status summaries and
interview record are kept, not normative, in [`../decision-ledger-archive.md`](../decision-ledger-archive.md).
