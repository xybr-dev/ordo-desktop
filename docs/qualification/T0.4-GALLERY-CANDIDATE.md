and emergency export consume:

## How this was generated

From the worktree root, through the running canonical-slide lab's own
pipeline (not a direct renderer call): every fixture loads with the lab's
loader, composes on the production canonical worker behind
`CanonicalCommand::Compose` at the default Theme and 100% density,
rasterizes at 100% with the lab's solid-gray GeneralImage stand-in, and
finishes through `ordo::canonical_views::finish_frame` — the same handoff
the operator viewports consume:

```text
ORDO_GALLERY_CAPTURE=$PWD/docs/qualification/gallery-candidate \
  cargo test -p ordo --example canonical-slide-lab --locked gallery_capture
```

The capture test
(`crates/ordo/examples/canonical-slide-lab.rs::gallery_capture_through_the_lab_pipeline`)
writes `docs/qualification/gallery-candidate/<name>.png` (all `1920x1080`
finished pre-chrome pixels) plus `capture-rows.md`: per-fixture provenance
carrying the visible frame, the wrapper, and the diagnostics riding beside
each capture. The table below is that manifest's exact output. Regenerating
reproduces these bytes; the captures stay candidate review artifacts and
never promote themselves to `design-references/`.

To review live instead of (or as well as) these captures:

```text
cargo run -p ordo --example canonical-slide-lab
```

`F2` cycles every fixture below, `F3` the viewport preset, `F4` the Interface
scale, `F5` the target density; diagnostics ride beside the scaled frame.

  notes only; no geometric overflow.

  1 authored line, 2 rendered lines, `fit=fits`, no warnings.
- `reading-identification-roma` and `reading-identification-mateo` (Roma/Mateo
  titles preserved sentence case at 135px/800): each 1 authored line, 3
  rendered lines, `fit=fits`, no warnings.
- `celebration-title` (title preserved mixed case at 135px/800 + subtitle
  `National Catechetical Day` at 68px/300): 1 authored body line, 4 rendered
  lines (3 title + 1 subtitle), `fit=fits`, no warnings; the three-line
