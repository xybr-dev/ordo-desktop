## 2. Manual scripts

### A. Atkinson operator fit + Noto fallback legibility — packaged Windows

- Setup: packaged Windows build on the church-PC-equivalent target; first at
  `1366x768`, then at `1920x1080`.
- Steps: launch `ordo`, open the canonical-slide lab
  (`cargo run -p ordo --example canonical-slide-lab` in a dev build, or the
  packaged equivalent surface); `F2` through every fixture, pausing on the
  long Cebuano/English passages, the missing-glyph slide, and both overflow
  warnings; `F4` through Interface scales `100%`–`200%`.
- Expected: Atkinson operator chrome stays fitted (no clipped/overlapping
  labels or controls); congregation slides are legible and stable at every
  scale; glyphs Atkinson lacks but Noto carries (`α`, `₱`) render through
  bundled Noto; a glyph neither bundled face carries (`中` in
  `lyrics-missing-glyph`) renders the bundled `.notdef` box, never a
  system-font glyph; overflow slides warn beside complete frames without
  clipping.
- Result: **passed** (2026-10-08, reviewer on Windows via the canonical-slide
  lab). Every fixture judged legible. `lyrics-missing-glyph` showed `α` and
  `₱` through Noto and `中` as the bundled `.notdef` box, matching the golden
  (`font=fallback id=0`) and confirming no system-font leak.
