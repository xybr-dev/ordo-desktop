## Outcome

Interface that UI and tests both drive: a pure, snapshot-driven
`presentation::engine::Engine` over the T1.1 `PresentationSnapshot`, with
explicit time for fades and auto-play. Three stacked micro-PRs:

## Shaping constraints

- **New module, old seams untouched.** `presenter.rs` (`PresenterEngine`, T0.6
  walking skeleton) and `lib.rs` (`PresentationEngine`, T0.2 frame seam) stay
  as they are; the qualification labs and their measurements depend on them.
  T1.4 moves Live Control onto the new Engine; retiring the old ones is a
  later cleanup, not this task.
- **Pure and deterministic.** No GPUI, no clock reads, no threads. Time
  enters only as `Millis(u64)` monotonic timestamps carried by
  `Engine::apply(command, now)` and `Engine::tick(now)`. Same snapshot +
  same (command, time) sequence ⇒ same states, always.
- **The engine works on Cue positions, not pixels.** Program is a
  `ProgramContent` (`Black` or `Frame { frame: FrameId, cue: usize }`); the
  frame identity is resolved to a canonical frame by the caller. Error frames
  cannot be represented, so "Program is always black, disconnected, or one
  complete valid frame" is structural, then checked by property tests.
- **State table (MVP-PLAN §8.1) as one enum** `LiveState`:
  `OutputDisabled`, `EnabledBlack`, `Live`, `Frozen`, `Blackout`,
  `Disconnected { display_back: bool }`.
- **Decision 274 overrides the T1.2 AC wording.** The AC says an unavailable
  future Cue "enters protective Freeze when necessary". Accepted Decision 274
  supersedes Decision 227: while linked Live, selecting an unavailable Cue
  makes Program black and linked Live continues; while Frozen/Blackout it
  stays as it is; `Space` on it is refused with the reason. The engine
  implements 274; the AC line is reworded in this PR and flagged.
- **Decision 273.** `F`/`B` toggle; turning either off does what `Space`
  does (and is refused the same way, leaving the state on). `F` during
  Blackout does nothing.
- **Decision 272.** Disconnected + same recognized display back ⇒ `Space`
  recreates output and takes Preview live in one step; otherwise refused.
  Reconnection alone never resumes output. Recognition is the platform's
  job (T1.6); the engine receives `DisplayReturned { recognized: bool }`.
- **Linked navigation.** While `Live`, navigation moves Preview and Program
  together: projectable ⇒ that frame; trigger/Hold/unavailable ⇒ black;
  Wait ⇒ Program unchanged. Frozen/Blackout/EnabledBlack/Disabled/Disconnected
  ⇒ Preview only.
- **Fade (DESIGN.md "output-blank-duration: 500ms").** Content↔black changes
  start a fade; content↔content cuts. The state transition is immediate; the
  fade is presentation of it: `program_view(now) -> ProgramView { shown:
  Option<FrameId>, opacity: f32 }`. A contrary change mid-fade reverses from
  the current opacity (remaining time proportional). Commands are never
  queued behind a fade.
- **Auto-play (MVP-PLAN §8.4).** `ToggleAutoPlay` on the Preview Cue's item;
  `LoopSection` on its section when every item in it with projectable Cues
  is an auto-play General Presentation. Each newly shown Cue gets its full
  duration (`MassItem::cue_duration_seconds`); last wraps to first within
  scope; non-projectable Cues inside scope are skipped. Navigation outside
  scope, Freeze, Blackout, disable/exit, recovery, or disconnect stops it;
  never resumes silently. Ineligible scope ⇒ refused with reason.
- **Repeated/unchanged commands are deterministic**: a command that changes
  nothing returns `Outcome::Unchanged` and does not bump `revision`.

## Interface (fixed by WP1)

```rust
pub struct Millis(pub u64);
pub enum Command { Next, Previous, NextItem, PreviousItem, First, Last, GoTo(usize),
    Take, ToggleFreeze, ToggleBlackout, EnableOutput, DisableOutput,
    DisplayLost, DisplayReturned { recognized: bool },
    ToggleAutoPlay, LoopSection, StopAutoPlay /* WP2 */ }
pub enum Refusal { UnavailablePreview { cue: CueId }, OutputDisabled, DisplayNotBack,
    OutputDisconnected, FreezeDuringBlackout, NotLive, AutoPlayIneligible /* WP2 */ }
pub enum Outcome { Changed, Unchanged }
pub struct EngineState { live: LiveState, preview: usize, program: ProgramContent,
    unavailable_black: bool, auto_play: Option<AutoPlay> /* WP2 */, revision: u64 }
impl Engine {
    pub fn new(snapshot: Arc<PresentationSnapshot>) -> Self; // OutputDisabled, preview 0
    pub fn apply(&mut self, command: Command, now: Millis) -> Result<Outcome, Refusal>;
    pub fn tick(&mut self, now: Millis) -> Outcome;           // WP2
    pub fn check(&self, command: Command, now: Millis) -> Result<Outcome, Refusal>; // dry run
    pub fn snapshot(&self) -> &Arc<PresentationSnapshot>;
    pub fn state(&self) -> &EngineState;
    pub fn program_view(&self, now: Millis) -> ProgramView;   // WP2
    pub fn preview_context(&self) -> Option<&str>;            // private operator context
}
```
