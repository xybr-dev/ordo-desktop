# T1.4 implementation plan

> Active plan. `MILESTONES.md` owns T1.4's status and acceptance gates; this
> file owns only the order in which the work lands. Freeze it at the gate close.

## Outcome

Live Control as one responsive GPUI view over the T1.2
`presentation::engine::Engine`: slim header, Ordo rail, grouped Cue timeline,
and Output Dock. Its composition comes from one pure
`presenter_layout(viewport, scale, rail_choice)` function. Every Cue thumbnail
and monitor draws the same completed logical `Frame` through one canonical
viewport element (Decision 310, retained path), differing only in fit scale.
Output commands go only through `Engine::apply`; resize, Interface scale,
Grid/List mode, rail pin/open, and rail jumps never reach the Engine. Reached
through a `live-control-lab` example until T1.6 adds Presenter Mode entry.

## Shaping constraints (verified)

- **Placement.** New `crates/ordo/src/presenter/` (`mod.rs` PresenterView,
  `layout.rs`, `frames.rs`, `dock.rs`, `timeline.rs`, `rail.rs`, `header.rs`)
  and a minimal `crates/ordo/src/commands/mod.rs` — one
  `dispatch(&mut Engine, Command, Millis) -> Result<Outcome, Refusal>` seam that
  buttons use now and T1.5's registry binds keys to. The old
  `presentation::presenter::PresenterEngine` stays untouched.
- **No Presenter Mode entry.** `ShellView`'s `EnterPresenter` only flips the
  environment (`crates/ordo/src/shell.rs:1135`); wiring is T1.6. Manual review:
  `cargo run -p ordo --example live-control-lab -- [--size 1366x768] [--scale 200] [snapshot-dir]`
  (default `tests/fixtures/presentations/normal-mass`).
- **Snapshot loading.** `snapshot_reader::read_snapshot(&DirectorySource::new(dir))`
  on the background executor, never the GPUI thread. Engine holds
  `Arc<PresentationSnapshot>`.
- **Engine drives the view, never the reverse.** The view owns `engine` and an
  injected clock `Rc<dyn Fn() -> Millis>` (production: `Instant` at session
  start; tests: a `Cell`). Rendering reads `state()`, `preview_cue()`,
  `preview_context()`, `program_view(now)`, `preview_view(now)`. Cue click →
  `GoTo(i)`, Freeze → `ToggleFreeze`, Blackout → `ToggleBlackout`, primary →
  `EnableOutput`/`Take`. Enablement from `engine.check(cmd, now).is_ok()`;
  refusals show as a polite status line. While a view is `fading` call
  `window.request_animation_frame()`; schedule `tick` from
  `engine.next_deadline()` on a view-owned timer task dropped on close. "No
  Engine mutation" = `state()` equal and `revision()` unchanged.
- **Pure layout** (`presenter/layout.rs`, `f32` + `ui::environment::InterfaceScale`):
  `presenter_layout(LayoutInput { width, height, scale, rail: RailChoice::{Auto, Pinned, Unpinned} })
  -> PresenterLayout { regime: Wide|Compact|Constrained, rail: Pinned{w}|Tab{w}|OverlayOnly{tab_w},
  dock: Side{width, monitor_width}|Band{monitor_width}, grid_columns, cell_width, gutter }`.
  Thresholds from the approved kit (`docs/mockups/ordo-kit.js:296-318`):
  effective width `W/scale` ≥1500 Wide, ≥1000 Compact, else Constrained. Wide:
  rail pinned by default 200px scaled, dock 520 (Decision 296). Compact: 28px
  ORDO tab, dock 360. Constrained: overlay-only rail, monitor band above the
  timeline. Side-dock monitors shrink with a short window:
  `monitor_width = min(dock_inner, (H − header − controls)/2 · 16/9)`
  (`ordo-kit.js:891-897`); band `monitor_width = min(⌊H·0.3·16/9⌋, (W − gutters − gap)/2)`
  (`ordo-kit.js:873`). Columns `clamp(⌊(inner+gap)/(scale·(270+4)+gap)⌋, 1, Wide?4:3)`;
  the 270px floor scales with Interface scale. Mirrors `shell::rail::collapsed`
  (`crates/ordo/src/shell/rail.rs:130`).
- **Identical canonical frames.** One element
  `canonical_views::live_viewport(frame: Arc<Frame>, images, width, env)`: a
  16:9 4px-radius black box hosting `performance::display_path::retained_frame`
  (`display_path.rs:175`, scales glyph origins to bounds). Gap: `paint_frame`
  paints only black + glyphs, not `Frame::image()`; the wrapper adds an
  absolutely positioned `img(Arc<gpui::Image>)` at the scaled `PlacedImage`
  bounds beneath the glyph canvas (raster order `rendering/src/raster.rs:139-157`).
  Frames come from T1.3's `rendering::FrameCache`/`FrameScheduler` (composed
  once per `FrameId` on the background executor; never recomposed on
  resize/scale). Lab runs `verify_bundled_faces` (`display_path.rs:291`) at
  startup and fails closed. Fade: overlay black at `1 − opacity`.
- **Grid/List preference.** `CueView::{Grid, List}` in `UiPreferences`
  (`crates/ui/src/environment.rs:65`) under optional key `cue-view=grid|list`
  (default Grid; old files stay valid), saved through the existing
  `save_preferences` worker path (`crates/ordo/src/lib.rs:446-457`). The lab
  writes under `target/live-control-lab/`, never `%APPDATA%`.
- **Grid floor / sparse rows.** Fixed `w(cell_width)` tiles, never `flex_grow`;
  keeping the floor removes a column. Triggers/Wait/Hold are full-width compact
  rows in both modes; Unavailable Cues are tiles captioned "Unavailable · …".
  Marks (Decision 295): Program Cue 2px ring (Live green / Freeze amber),
  Preview Cue 3px neutral bar, each with its caption word. One-line captions,
  label ellipsizes (Decision 303).
- **Rail scrolls, never filters.** Section labels + Mass-item titles only. The
  timeline is `ui::Scroll` (`crates/ui/src/scroll.rs:61,147`) with one child
  group per Mass item; a rail click calls `ScrollHandle::scroll_to_top_of_item`
  (gpui `src/elements/div.rs:4332`). Unpinned: ORDO tab opens an overlay over a
  dim scrim; scrim click consumed, closes, restores focus to the active Cue.
  Hover never opens. Pin hidden in Constrained; pin choice remembered for the
  session (Decision 237).
- **Output Dock order (Decision 65).** Program monitor + state label; Preview
  monitor + item + private context; output status; Freeze/Blackout (40px,
  `tokens::density::PRESENTER_CONTROL`); primary area (Decision 61, amended by
  272): OutputDisabled → **Enable Output**; EnabledBlack/Frozen/Blackout →
  **Take Preview Live**; Live → non-action **LIVE — navigation updates
  Program**; Disconnected{back} → **Resume Output** (`Take`);
  Disconnected{!back} → non-action "Waiting for the congregation display"
  (Select display… is T1.6). Dock/band controls never scroll; the whole
  Presenter never scrolls.

Selectors: `presenter-rail`, `ordo-tab`, `cue-timeline`, `output-dock`, `monitor-band`, `monitor-program`, `monitor-preview`, `output-status`, `button-Freeze`, `button-Blackout`, `primary-action`, `cue-{i}`, `rail-item-{i}`, `group-{i}`.
