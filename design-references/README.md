# Ordo design references

This folder now holds only the approved Canonical Slide Layout Gallery,
`ordo-canonical-slide-layouts/`: `1920x1080` PNG captures of every canonical
template plus `capture-rows.md` provenance. It is renderer output, written by
the `canonical-slide-lab` capture test, so it stays at this path. View it in
[`docs/mockups/canonical-slide-layouts.html`](../docs/mockups/canonical-slide-layouts.html).

The HTML explorations that used to live here moved to
[`docs/mockups/`](../docs/mockups/index.html), one page per screen with its
status, decisions and superseded details (Decision 271). Their former names map
directly: `ordo-presenter-high-scale*` is `docs/mockups/presenter-high-scale.html`,
and so on; the `*-standalone.html` copies were dropped because each page now
opens directly.
